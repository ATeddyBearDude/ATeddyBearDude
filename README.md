# Olympiad Atlas

An infinite-canvas star map of the world's major STEM competitions and olympiads,
rendered as a liquid-glass night sky.

- **Drag** to roam, **scroll** to zoom, **click** any card for a dossier with what
  the competition is, a brief history, the official website, and a past-problems archive.
- Physics and astronomy/astrophysics sit at the map's origin; mathematics, informatics,
  chemistry, biology, earth sciences, research fairs, and curiosities orbit around them.
- Single self-contained file — no build step, no dependencies. Open `index.html`
  in a browser, or serve the repo with GitHub Pages.

37 competitions across 9 constellations, from the IMO (est. 1959) to EGOI (est. 2021).
